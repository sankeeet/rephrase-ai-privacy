Privacy Policy

Last updated: November 26, 2026

Rephrase AI is an independent Chrome extension that helps users rewrite selected text using the OpenAI API. This policy explains what information the extension handles and how it is used.

1. Information the Extension Handles

  • Text you select and submit for rewriting.
  • Your selected writing tone and optional custom instructions.
  • Your OpenAI API key.
  • Your selected AI model preference.

2. How Information Is Used

When you request a rewrite, the extension reads your saved settings and sends the selected text, requested tone and applicable custom instructions to the OpenAI API. Your API key is included to authenticate the request. The generated response is returned to the extension for you to review, copy or use to replace selected text.

3. Storage and Processing

  • The API key, model preference and custom instructions are stored using Chrome's local storage.
  • Rephrase AI does not currently operate its own backend server.
  • Rewriting requests are sent directly from the extension to OpenAI.
  • Selected text is transmitted to OpenAI when you request a rewrite.

Important: Chrome local storage is not an encrypted secrets vault. Other software or people with access to your browser profile or device may potentially access locally stored information. Protect your device and API key accordingly.

4. Third-Party Services

Rephrase AI uses the OpenAI API to generate rewritten text. Information included in API requests is transmitted to OpenAI and processed under OpenAI's applicable terms and policies.

  • OpenAI Privacy Policy
  • OpenAI Terms of Use

5. Data Sharing

The project does not currently operate its own backend or analytics service. Information submitted for rewriting is sent to OpenAI to fulfil your request. The extension does not intentionally send this information to another service.

6. User Responsibilities

  • Keep your API key private.
  • Manage your OpenAI account and API usage costs.
  • Review OpenAI's applicable data-handling policies.
  • Avoid submitting passwords, confidential business information, sensitive personal information or data you are not authorized to share.
  • Review AI-generated content before using it.

7. Data Retention and Deletion

You can remove your saved API key and other extension settings using the available settings controls or by removing the extension and its associated data through Chrome. Information transmitted to OpenAI is subject to OpenAI's applicable data retention and processing policies. Rephrase AI does not control OpenAI's retention practices.

8. Changes to This Policy

This policy may be updated as the project evolves, particularly when new features, integrations or data-processing practices are introduced. The latest version will be maintained in this repository.

9. Contact

For questions, feedback or privacy-related concerns, please use the project's GitHub repository.
